DEPLOY ON RENDER (free)
1. Upload this folder to a GitHub repo.
2. Render -> New -> Web Service -> pick the repo.
3. Build Command:  npm install
   Start Command:  npm start
4. Open the .onrender.com link (https).

If sites will not load, add ?transport=epoxy to the end of your link and try again.
Own computer: install Node 20+, then  npm install  and  npm start  -> http://localhost:8080
